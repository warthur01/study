Em programação, DAO (Data Access Object ou Objeto de Acesso a Dados) é um padrão de projeto que separa a lógica de acesso a dados de uma aplicação, como a interação com bancos de dados, da lógica de negócios. Isso é feito através de uma classe específica, o DAO, que é responsável por criar, ler, atualizar e excluir dados (CRUD). As vantagens incluem facilidade de manutenção, pois mudanças no banco de dados afetam apenas o DAO, e a abstração, onde a lógica de negócio não precisa conhecer os detalhes de como os dados são armazenados ou recuperados.
