O Hibernate é um framework (estrutura de suporte) para Java que implementa o padrão ORM (Object Relational Mapping), ou Mapeamento Objeto-Relacional. Ele funciona como um intermediário, traduzindo automaticamente objetos Java em comandos SQL e dados de tabelas de bancos de dados relacionais de volta para objetos Java, simplificando o acesso e a persistência de dados sem a necessidade de escrever SQL manualmente. O Hibernate não apenas mapeia classes e tipos de dados entre a aplicação Java e o banco de dados, mas também oferece funcionalidades de consulta e recuperação de dados, gerando as chamadas SQL necessárias para as operações.
